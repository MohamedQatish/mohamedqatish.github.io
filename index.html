ROADMATE — Syrian Driver Vehicle Services Platform

University Capstone
Backend Developer & Domain Architect

A 15-domain modular backend unifying all vehicle-related services for Syrian drivers: verified identity onboarding via government-issued invitation codes, online traffic-violation and mandatory-insurance payments, SOS emergency response with live GPS tracking, an Arabic RAG-powered legal assistant, and voice-driven maintenance logging — all behind one secure, bilingual, versioned API.

Key Achievements:

  • Delivered a 15-domain DDD backend (515 files, ~37,930 LOC, 97 use cases, 51 contracts, 65 DTOs) with strict layered separation, exposing 107 versioned REST endpoints
  • Engineered the SOS emergency domain (10 use cases, 4 domain events, 4 listeners) with tokenized public live-tracking map
  • Implemented layered security: Sanctum 15-min tokens + SHA-256 refresh tokens, 4-role/~24-permission RBAC, 46 validated requests, 4 rate-limit tiers
  • Built resilient integrations: Circuit Breaker (5-failure/60s cooldown), retry/timeout, pluggable Mock↔Real gateways, external-sync audit log
  • Delivered unified idempotent payment layer (Paymera) for 3 payable types with event-driven activation
  • Built Arabic voice-to-data pipeline using Groq Whisper + Llama 3.3 70B for structured maintenance records
  • Authored 111 test files within a 431-test / 1,410-assertion PHPUnit 11 + Mockery suite
